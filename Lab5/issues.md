# Static Code Analysis Issues - `pharmacy_manager.py`

| Issue | Type | Line(s) | Description | Fix Approach |
|-------|------|---------|-------------|--------------|
| Command injection in `printLabel` (`B605`) | Security (High) | 68 | Uses `os.system("echo Dispensing label: " + name)` which spawns a shell and allows command injection if `name` has shell characters. | Replace `os.system` with a normal `print(f"Dispensing label: {name}")` statement. |
| Weak MD5 hash for patient ID (`B324`) | Security (High) | 51 | `patientId` uses `hashlib.md5()` which is weak and collision-prone. | Switch to `hashlib.sha256()` for hashing patient name and phone. |
| Unsafe `eval()` in `calculateDosage` (`B307` / `W0123`) | Security (Medium) | 48 | `eval(formula)` runs arbitrary Python code if someone passes malicious input instead of a dosage formula. | Split the formula string on `"*"` and multiply the float values directly without `eval()`. |
| Unsafe `pickle` serialization (`B301` / `B403`) | Security (Medium) | 3, 58, 64 | `saveStock` and `loadStock` use `pickle`, which can execute arbitrary code when loading untrusted files. | Replace `pickle` with `json.dump()` and `json.load()` using a `.json` file. |
| Mutable default argument `audit=[]` (`W0102`) | Bug | 13 | `addMedicine` uses `audit=[]` as a default argument, so the same list gets shared across all calls. | Change the default to `audit=None` and initialize `audit = []` inside the function. |
| Missing input checks in `addMedicine` | Bug / Logic | 13-18, 92-93 | `addMedicine` allows negative stock (`-10` for Cetirizine) and integer names (`404`), which messes up the stock report. | Check that `name` is a non-empty string, `qty > 0` (int), and `price >= 0` before adding stock. |
| Bare `except: pass` (`B110` / `W0702` / `E722`) | Bug / Security (Low) | 27-28 | `dispenseMedicine` uses a bare `except: pass`, hiding missing medicine errors (like dispensing `Insulin` when it is not in stock). | Catch `KeyError` specifically and print a message when the medicine is not found. |
| Hardcoded password (`B105`) | Security (Low) | 11, 79 | `DB_PASSWORD = "pharma@123"` is hardcoded in the script and checked with `==`. | Read the password from `os.environ.get("PHARMA_DB_PASSWORD", "pharma@123")` and check with `secrets.compare_digest`. |
| Predictable random number (`B311`) | Security (Low) | 5, 54 | `generateRxNumber` uses `random.randint()`, which is not cryptographically secure. | Use `secrets.randbelow(900000) + 100000` instead. |
| File handling without `with` (`R1732`) and `global` (`W0603`) | Code Quality | 57-65 | `saveStock` and `loadStock` manually open/close files without `with`, and `loadStock` uses `global medicines`. | Use `with open(..., encoding="utf-8")` and update `medicines` in place with `.clear()` and `.update()`. |
| PEP 8 formatting, naming, docstrings, unused imports (`C0103`, `C0114`, `C0116`, `W0611`, `E302`, `E501`) | Style / Quality | 1-108 | Unused `sys` and `logging` imports, camelCase function names, missing docstrings, lines over 79 characters, and missing 2 blank lines between functions. | Remove unused imports, rename functions to `snake_case`, add docstrings, wrap long lines, and add 2 blank lines between functions. |
