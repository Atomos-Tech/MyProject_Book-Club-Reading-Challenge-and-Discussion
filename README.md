# Book Club Reading Challenge and Discussion Portal

This repository contains the individual Software Engineering project submission for Problem Statement 55. The proposed portal helps book-club members set reading goals, record progress, discuss books without accidental spoilers, and vote once in each monthly book-selection poll.

## Project scope

The portal supports three actors:

- **Club Member** — sets a reading goal, records progress, participates in discussions, reveals spoiler-tagged content intentionally, casts one vote, and views poll results.
- **Discussion Lead** — creates and manages the monthly book-selection poll.
- **System Administrator** — manages club membership and system operation.
