# Software Testing Practice

This folder is prepared for the separate instructor-issued game-application testing exercise.

## Required evidence

1. Link to the assigned game repository.
2. Short explanation of what the game does.
3. Environment and test-tool setup.
4. The four supplied test cases and their initial results.
5. Reproduction evidence for the identified defect.
6. Root-cause analysis.
7. The code patch or commit reference.
8. Retest results showing the affected test and regression tests.
9. Link to the corrected repository.

## Files

- [Testing_Process.md](Testing_Process.md) — repeatable procedure for cloning, running, diagnosing, fixing, and retesting the assigned application.
- [Test_Case_and_Retest_Record.md](Test_Case_and_Retest_Record.md) — evidence table for the four supplied cases and final retest.
